# Screenshots Directory

Place the showcase screenshots in this directory with the following filenames:

- `home_screen.png` — Main home feed screen.
- `details_screen.png` — Anime details and episodes screen.
- `search_screen.png` — Search and filters screen.
- `carousel_screen.png` — Random anime discovery carousel.
- `favorites_screen.png` — Bookmarks and watch history screen.
- `profile_screen.png` — Settings, appearance, and profile screen.
